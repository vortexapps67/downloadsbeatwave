DOCUMENT 01

PRIVACY POLICY

DATE INDEX: AUGUST 25, 2026

BeatWave is developed by BeatLabs. We believe that your privacy is a absolute right. Our application is built as an offline-first music client. Your library, cache, and configuration metrics are strictly preserved on local storage.

1. STORAGE DATA

All database instances are structured locally on SQLite/Room engines. We maintain no remote synchronization cloud infrastructure for your libraries.

2. TELEMETRY

There are no diagnostic modules or analytical tracker software (such as Firebase Analytics, Flurry, or Crashlytics) included in the packages. Crashes are saved solely on your storage diagnostics.

3. NETWORKING SERVICE

  • YT Music Integration: Streaming tasks query public API endpoints directly. Query records conform to external terms.
  • Listen Together: Peer sync uses Network Service Discovery (mDNS). Sync protocols run strictly on local networks.

4. PERMISSIONS

We demand file systems read permission (MediaStore access) to parse your local audios, and local network checks to launch sync streams. You can change these constraints anytime.
